# Тестирование REST API

В этом проекте я тренировался тестировать **REST API**. Проект написан на **Java** и **Spring Boot**.

Тесты находятся в папке `src/test/java/sberjv3`. Написаны модульные тесты для каждого слоя приложения, а также интеграционные тесты.

Для создания заглушек используется фреймворк **Mockito**.

## Запуск тестов

В корне проекта: `./mvnw test`
